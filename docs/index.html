mnBazz

Monophonic bass synthesizer. Two oscillators, sub, ladder filter, and enough factory presets for house, techno, and trance lines.

Installer 1.0 All releases
OSC

Saw, square, triangle. Two oscillators with octave and cent detune. Sub is a square one octave below OSC 1.

Filter

4-pole ladder, resonance, and drive in the filter path. Envelope and key tracking move the cutoff.

Env

Separate ADSR for filter and amplitude. Each card shows its envelope shape.

LFO

Five waveforms for cutoff and pitch. Mod wheel opens the filter.

One note at a time.

  1. OscillatorsOSC 1 feeds the sub. OSC 2 is detunable in cents, −2…+2 octaves.
  2. Ladder filterFilter ADSR moves cutoff in bipolar range. Drive saturates inside the ladder, not as a post effect.
  3. AmpIts own ADSR, then light DC blocking on the output.
  4. PlayRetrig or legato, glide, pitch bend. Monophonic voice.

On screen

Colour follows the signal path: amber for oscillators and output, coral for the filter, cyan for envelopes, violet for the LFO. The output card has a scope, the filter card shows the curve, envelope cards show their shapes.

Fixed aspect ratio, resizable window.

Install

Windows x64. The installer always copies the VST3 to the common plug-in folder. Standalone is optional and unchecked by default; when selected, it installs to Program Files and adds a Start menu shortcut. Run as administrator, then rescan plug-ins in your DAW.

VST3         C:\Program Files\Common Files\VST3\mnBazz.vst3
Standalone   C:\Program Files\mnBazz\mnBazz.exe

Use on an instrument track: MIDI in, audio out.

Build from source

cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

CMake 3.22+, Visual Studio C++ toolchain, Git. JUCE 8.0.8 is fetched by CMake. Details in the README.
